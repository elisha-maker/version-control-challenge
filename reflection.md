## Reflection (100–150 words)

**What did I learn about version control?**
I learned that version control is much more than just saving files. It provides a complete history of a project, allowing you to track every change, understand why it was made, and collaborate with others without conflicts. Git and GitHub together create a powerful system where local work and remote collaboration are seamlessly connected.

**What was the most difficult step?**
The most challenging step was understanding the feature branch workflow — specifically, knowing when to create a branch, how to keep it focused on a single improvement, and how the pull request process works to review and merge changes back into the main branch.

**Why are branches and pull requests useful?**
Branches let you work on new features or fixes in isolation, so you do not break the working code on the main branch. Pull requests add a layer of review before changes are merged, ensuring code quality and enabling team discussion about proposed changes. Together, they make collaboration safe, organized, and transparent.
