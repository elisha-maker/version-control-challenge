## Beginner Checklist

Use this checklist to track your progress as you learn Git and GitHub:

- [ ] Install Git on your machine
- [ ] Create a GitHub account
- [ ] Configure your Git username and email
- [ ] Create your first repository
- [ ] Make your first commit
- [ ] Push changes to GitHub
- [ ] Create a branch
- [ ] Open a pull request
- [ ] Merge a pull request
- [ ] Collaborate on someone else's repository

## Tips for Success

1. **Practice daily** — Even small commits help build muscle memory
2. **Read error messages** — Git error messages usually tell you exactly what to do
3. **Use `git status` often** — It shows you exactly where you are in the workflow
4. **Don't be afraid to experiment** — You can always create a test repository to try new things
5. **Ask for help** — The Git and GitHub communities are welcoming and supportive
